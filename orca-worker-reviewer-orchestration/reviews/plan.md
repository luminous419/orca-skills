# PLAN Review Policy

Common Review Policy와 함께 적용한다.

검토:
- 목표, scope와 out-of-scope가 사용자 요청에 맞는가?
- work item, dependency와 실행 순서가 실제 repository에 타당한가?
- 계획이 필요 이상으로 확대되지 않았는가?
- validation/test 계획과 completion criteria가 충분하고 검증 가능한가?
- 위험과 제약이 반영되었는가?

FAIL 예:
- 핵심 work item 또는 validation 계획 누락
- 실제 구조/의존성과 충돌하는 순서
- 요구사항보다 과도한 scope
- 완료 조건이 모호하거나 검증 불가능
