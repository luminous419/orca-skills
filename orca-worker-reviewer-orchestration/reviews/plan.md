# PLAN Review Policy

Common Review Policy와 함께 적용한다.

검토:
- 목표와 scope가 사용자 요청과 일치하는가?
- work item이 실제 repository와 기술적으로 맞는가?
- dependency와 실행 순서가 타당한가?
- 불필요한 작업이 포함되지 않았는가?
- validation/test 계획이 충분한가?
- completion criteria가 명확한가?
- 위험과 제약이 반영되었는가?

FAIL 예:
- 중요한 work item 누락
- 실행 순서가 dependency와 충돌
- 실제 구조와 맞지 않는 계획
- validation/test 계획 부재
- scope가 요구사항보다 과도하게 확장됨
